# 雪地语资料库

雪地语（Yendene / Suveddene）的人造语言资料网站。

本站使用 Astro + Starlight 构建，并通过 Cloudflare Pages 部署。

本项目当前部署在https://yendene-language.pages.dev/

## 项目结构

Inside of your Astro + Starlight project, you'll see the following folders and files:

```
.
├── public/
│   └── favicon.svg
├── src/
│   ├── assets/
│   ├── content/
│   │   └── docs/
│   │       ├── articles
│   │       ├── grammar
│   │       ├── texts
│   │       ├── tools
│   │       └── world
│   └── content.config.ts
├── scripts/
│   └── validate-dictionary.mjs
├── astro.config.mjs
├── package.json
├── package-lock.json
├── tsconfig.json
└── README.md
```

## 内容

包括一些系列文章、专栏和工具，以及配套的世界设定等等，是一个语言文化资料库
