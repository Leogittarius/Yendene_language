# 雪地语资料库

雪地语（Yendene / Suveddene）的人造语言资料网站。

本站使用 Astro + Starlight 构建，并通过 Cloudflare Pages 部署。

## 项目结构

Inside of your Astro + Starlight project, you'll see the following folders and files:

```
.
├── public/
├── src/
│   ├── assets/
│   ├── content/
│   │   └── docs/
│   └── content.config.ts
├── astro.config.mjs
├── package.json
└── tsconfig.json
```

## 内容

- 语言介绍
- 音系
- 语法
- 词典
- 例文
- 设计文章

## Development

npm install
npm run dev

## Build

npm run build
